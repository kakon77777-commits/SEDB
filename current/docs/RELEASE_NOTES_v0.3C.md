# SEDB v0.3C Release Notes

Version: `0.3.0c1`  
Date: 2026-08-23  
Checkpoint: **Governed AI Field Agent Kernel**

## Core change

v0.3C adds a provider-neutral advisory Agent runtime on top of the existing field, semantic, utility, and family governance layers.

$$
\boxed{\text{AI Autonomy}\neq\text{Canonical Authority}}
$$

A complete autonomous run may create field proposals, semantic candidates, utility assessments, and family proposals, but it cannot directly create a canonical field, change a cell, merge/split fields, apply lifecycle recommendations, or review a family into canonical state.

## Added

- `field_agent_runs` with bounded policy/counters;
- immutable `field_agent_observations`;
- immutable `field_agent_actions` receipts;
- append-only `field_agent_run_events`;
- `DeterministicDiscoveryBackend` reference harness;
- provider-neutral `ExternalSuggestionBackend`;
- capability allow/deny gate;
- explicit denied mutation receipts;
- step/observation/proposal/score/family/assessment budgets;
- immediate canonical/alias re-resolution before proposal creation;
- same-run suggestion de-duplication and pending-proposal idempotence;
- advisory orchestration through existing proposal, semantic, utility, and family services;
- deterministic and external local HTTP run endpoints;
- Browser **AI Field Agent** receipt panel;
- governance demo and bounded observation benchmark.

## Explicit non-goals

v0.3C does not bundle or call an LLM provider, does not use an API key, does not give an Agent proposal-decision authority, and does not expose canonical mutation endpoints through the Agent API.

## Safety invariant

For an autonomous run:

$$
|F_{t+1}|=|F_t|,
$$

and the same applies to canonical sparse cells. Advisory artifact counts may increase.

A mutation intent such as `set_cell`, `merge_fields`, or `apply_assessment` receives a persisted `DENIED` receipt rather than executing.


## Packaged validation evidence

The release includes two fresh v0.3C SQLite fixtures generated by `examples/agent_demo.py`.

### Governance fixture

`demo/sedb-agent-governance-v0.3c.sqlite` records four Agent runs covering deterministic discovery, an external suggestion adapter, an explicitly denied mutation intent, and budget exhaustion.

```text
canonical fields before runs: 2
canonical fields after runs:  2
canonical cells before runs:  1
canonical cells after runs:   1
field proposals created:      3
semantic candidates created:  4
utility assessments created:  2
denied mutation receipts:     1
budget run proposals created: 0
budget run status:            budget_exhausted
```

The denied mutation receipt is for `set_cell`. The canonical field and sparse-cell counts remain unchanged across the autonomous Agent runs.

### Deterministic observation benchmark

`demo/sedb-agent-observation-v0.3c.sqlite` records a provider-free structural-discovery run over 2,000 input records sharing 20 discoverable fields:

```text
records:              2,000
field width:          20
proposals created:    20
steps:                21
canonical fields:     0 -> 0
canonical cells:      0 -> 0
run status:           completed
elapsed in this release environment: 0.867795 seconds
```

The elapsed time is evidence for this exact fixture and execution environment only. It is not a cross-machine or production performance guarantee.

Exact machine-readable results are stored in `demo/agent-stats-v0.3c.json`, and the two v0.3C SQLite fixture hashes are stored in `demo/DEMO_SHA256_v0.3C.txt`.
